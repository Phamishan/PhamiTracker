# PhamiTracker - Every RP Counts, Even When You're Offline ✨

## Features:

```
🪂 - Apex Legends tracking
🔫 - VALORANT tracking
🔀 - Switch between games
☁️ - Live tracking in the cloud (works with the app closed)
⚡ - RP/RR earned today
🎯 - Rank goal with split countdown & RP/day pace
📊 - Win rate
📈 - Climb chart (last 14 days)
📜 - Match history (legend/agent, map, K/D/A)
🗺️ - RP/RR per map
🔄 - Apex map rotation with countdown
📱 - Home screen & lock screen widgets (RP Today, Rank Goal, Climb, Map Rotation)
🆓 - Free
⛔ - No ads
```
